Organizador de Arquivos em Python

Objetivo: Crie um script para organizar arquivos automaticamente por tipo.

Instruções:
1. Baixar arquivos: Baixe e descompacte a pasta Automação 1.0 em seu computador.

2. Analisar extensões: Identifique as extensões de cada arquivo presente na pasta (ex: .pdf, .png, .xlsx, .jpg).

3. Criar o script: Na raiz da pasta Automação 1.0, crie o arquivo organiza.py.

4. Implementar a lógica: Escreva o código Python necessário para mover cada arquivo para sua respectiva pasta de destino.
---- Exemplo: Arquivos .png e .jpg devem ser movidos para a pasta Imagens (criando a pasta caso ela ainda não exista).

5. Implemente a lógica: Escreva o código Python necessário para criar o desorganiza.py, movendo os arquivos das subpastas para a pasta raiz e, posteriormente, excluindo as pastas que ficaram vazias.

6. Criar a interface gráfica: A interface deve ser simples e intuitiva, contendo opções para selecionar a pasta, Organizar arquivos e Desorganizar arquivos, além de mensagens informando o resultado da operação. 

7. Criar o executável: Utilize o PyInstaller para transformar os arquivos organiza.py e desorganiza.py em arquivos executáveis (.exe), permitindo que os programas sejam executados em computadores sem a necessidade de abrir o código Python.
Abra o Terminal/CMD diretamente na pasta onde está o arquivo que tem sua interface gráfica com as funções organiza e desorganiza.
Comando: python3 -m PyInstaller --onefile --windowed --clean --noconfirm --name "Nome do arquivo final" nome_arquivo_com_interface.py
Substitua Nome do arquivo final pelo nome que deve chamar seu arquivo executável, o meu chamará Organizador
Substitua nome_arquivo_com_interface.py pelo nome do seu arquivo em Python quem contem o programa principal, o meu chamará interface.py
Exemplo: python3 -m PyInstaller --onefile --windowed --clean --noconfirm --name "Organizador" interface.py
