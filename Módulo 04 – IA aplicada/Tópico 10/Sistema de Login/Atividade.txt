Sistema de Login com Interface Gráfica e Planilha Excel

Desenvolva, em Python com Tkinter, um sistema de login que autentica usuários a partir de uma planilha Excel (usuarios.xlsx) com as colunas Nome, Login, Senha, Status (Ativo/Inativo) e Nível (Usuário/Administrador).

A tela deve conter campos para usuário e senha, sendo que a senha deve ser exibida de forma oculta. O botão Entrar deve realizar o login e a autenticação também deve funcionar ao pressionar a tecla Enter. O sistema deve validar, nessa ordem: campos vazios, login/senha incorretos (mensagem genérica) e usuário inativo (mensagem específica). Login correto exibe mensagem de boas-vindas com o nome do usuário.

Se o usuário for Administrador, uma segunda tela deve abrir automaticamente listando todos os usuários (nome, login, senha, status) em formato de tabela, com contador de total e botão para fechar. Usuários comuns não podem acessar essa tela.
O código deve ser organizado (lógica separada da interface), com nomes e comentários claros, e tratar erros ao carregar a planilha (arquivo ausente/corrompido).
