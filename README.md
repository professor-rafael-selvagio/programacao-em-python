# 🐍 Curso de Programação em Python

Repositório oficial do curso de **Programação em Python**, desenvolvido com foco em aprendizado prático, lógica de programação e desenvolvimento de projetos.

Aqui estão disponíveis os materiais utilizados durante o curso, incluindo exemplos, exercícios, códigos e projetos.

---

## 📌 Sobre o curso

O curso apresenta os principais conceitos da programação utilizando Python, desde os fundamentos da lógica de programação até o desenvolvimento de aplicações práticas.

Durante as aulas, os alunos foram incentivados a aprender por meio da prática, resolução de problemas, experimentação e desenvolvimento de projetos.

---

## 🎯 Objetivos

Ao longo do curso, os alunos desenvolveram conhecimentos para:

- Compreender os fundamentos da programação;
- Desenvolver o raciocínio lógico;
- Criar programas utilizando Python;
- Trabalhar com diferentes estruturas de dados;
- Criar e utilizar funções e módulos;
- Manipular arquivos e dados;
- Tratar erros e exceções;
- Automatizar tarefas;
- Desenvolver aplicações práticas;
- Criar jogos simples utilizando Pygame;
- Utilizar ferramentas de Inteligência Artificial como apoio ao aprendizado e desenvolvimento.

## 🚀 Metodologia

O curso foi baseado em **aprendizagem prática**, utilizando exemplos, exercícios e projetos para aproximar os conceitos de programação de situações reais.

A proposta foi estimular:

- Raciocínio lógico;
- Resolução de problemas;

- Experimentação;
- Autonomia;
- Trabalho com projetos.

## 🎓 Ao final do curso
